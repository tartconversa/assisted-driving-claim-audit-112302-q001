# 资料契约

本目录只含本地合成记录，不包含真实驾驶员、车辆或道路资料。新闻报道描述的是厂商发布信息及公开说明，不是本资料集中的实测结论。

| 文件 | 字段 | 记录数 |
| --- | --- | ---: |
| `claims.csv` | `claim_id`, `version`, `region`, `scenario_scope`, `wording`, `status` | 2 |
| `trip_summaries.csv` | `trip_id`, `version`, `vehicle_group`, `region`, `weather`, `trip_km`, `upload_coverage` | 30 |
| `scenario_events.csv` | `event_id`, `trip_id`, `scenario`, `event_type`, `review_status`, `review_batch` | 30 |
| `reviews.csv` | `review_id`, `claim_id`, `source_ref`, `scope_hash`, `decision`, `reviewed_at` | 12 |

输入文件之间通过明确的标识字段关联。记录时间均为 UTC 或 ISO 日期。缺失覆盖、待复核和撤回状态是有效业务事实，不能自动解释为零事件或成功。事件标签、回执、版本和授权范围以各行记录为准。所有示例数值由固定种子构造，仅供本地数据流程开发与测试。
